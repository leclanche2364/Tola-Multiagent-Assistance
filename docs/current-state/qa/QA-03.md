### Adversarial Checks (self-designed)
1. **Concurrent double-claim (same key+timestamp):** Two parallel psql sessions raced to claim `autoY` at identical `scheduled_for`. Result: S1=`claimed`, S2=`already_claimed`, exactly 1 row in `automation_occurrences`. **PASS** — row-level locking serializes correctly.
2. **Consume approval after expiry:** Inserted approved approval with `expires_at = now() - 2min`. `consume_approval` returned `expired` and status flipped to `expired`. **PASS**
3. **Payload mismatch rejected:** `consume_approval` with wrong hash returned `payload_mismatch`; `consumed_at` remained NULL. **PASS**
4. **Unauthorised anon write to external_operations:** `SET LOCAL ROLE anon; INSERT INTO external_operations ...` → `ERROR: permission denied for table external_operations`. **PASS** — RLS deny-all + revoke works.
