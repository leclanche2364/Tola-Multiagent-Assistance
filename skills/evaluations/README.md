# skills/evaluations

## Purpose

Behavioural fixtures used to evaluate skill candidates during quarantine intake. Each candidate must have evaluation fixtures that test targeted behaviour improvement without boundary regression.

## Lifecycle Rules

- **Behavioural fixtures.** Evaluation fixtures encode expected behaviour — what the skill should do and what it must not do.
- **Baseline evaluation required.** A candidate must improve targeted behaviour without regressing boundaries.
- **Malicious/overbroad candidates rejected.** Fixtures that reveal unsafe behaviour (privilege escalation, data exfiltration, unbounded scope) result in quarantine rejection.
- **Created at intake.** Evaluation fixtures are generated during the quarantine intake process.
- **Gate for promotion.** A candidate cannot graduate from quarantine without passing its evaluation fixtures.
